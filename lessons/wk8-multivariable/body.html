Lesson 22 · optimization with a constraint

Lagrange multipliers

The big idea

To find the max or min of \(f\) while you're stuck on a curve \(g = 0\), look for the spots where a level curve of \(f\) just touches the constraint curve. There, the two gradients point along the same line: \(\nabla f = \lambda \nabla g\).

Topic 1 · from first principles

The idea: where a level curve touches the constraint

Two tools from earlier lessons do all the work:

Level curves

The curve \(f(x,y) = c\) connects every point where \(f\) has the same value \(c\). They're the contour lines on a hiking map.

The gradient

\(\nabla f = \langle f_x, f_y\rangle\) points straight uphill. It is always perpendicular to the level curve through that point, and its length says how steep the climb is.

A constrained problem says: optimize \(f(x,y)\), but only at points on a curve \(g(x,y) = 0\). The unconstrained peak may not even be on the curve, so setting \(\nabla f = \mathbf{0}\) won't work.

Analogy · a hiking trail

You're hiking a trail that cuts across a hillside. The trail is the constraint; the hill's height is \(f\). You want the highest point on the trail, not the summit. While the trail crosses contour lines you're still climbing or descending. At the trail's highest point it stops crossing contours and runs along one for an instant: the trail is tangent to a level curve.

At that tangent point, \(\nabla f\) is perpendicular to the level curve and \(\nabla g\) is perpendicular to the constraint curve. The two curves share a tangent line there, so the two perpendiculars point along the same line. One must be a multiple of the other:

Lagrange multipliers · one constraint

If \(f\), restricted to the curve \(g(x,y) = 0\), has a local extremum at \((x_0,y_0)\) and \(\nabla g(x_0,y_0) \ne \mathbf{0}\), then there is a number \(\lambda\) (the Lagrange multiplier) with

\[\nabla f(x_0,y_0) = \lambda\,\nabla g(x_0,y_0).\]

\(f\) is the objective function; \(g = 0\) is the constraint. \(\lambda\) can be negative: the gradients may point in opposite directions.

Gradient explorer

Drag the point along the constraint (or use the slider). Away from the answer, the dashed level curve crosses the constraint and the arrows disagree. At a max or min, the level curve just touches it and the arrows line up.

Quick check: at a point, \(\nabla f = \langle 6,-8\rangle\) and \(\nabla g = \langle 3,-4\rangle\). Is it a candidate? What is \(\lambda\)?

Yes. \(\langle 6,-8\rangle = 2\,\langle 3,-4\rangle\), so the gradients are parallel and \(\lambda = 2\).

Topic 2

The method in four steps

  1. Name the pieces

    Find the objective \(f(x,y)\) and the constraint \(g(x,y) = 0\). Are you maximizing or minimizing?

  2. Set up the system
    \[\nabla f(x_0,y_0) = \lambda\,\nabla g(x_0,y_0), \qquad g(x_0,y_0) = 0\]

    Written out, that's three equations (\(f_x = \lambda g_x\), \(f_y = \lambda g_y\), \(g = 0\)) in three unknowns (\(x, y, \lambda\)).

  3. Solve for \(x_0\) and \(y_0\)

    You usually don't need \(\lambda\) itself; it's a go-between.

  4. Compare

    Plug every solution into \(f\). The largest value is the max, the smallest is the min.

Solving tips. Solve each of the first two equations for \(\lambda\) and set them equal; that links \(x\) and \(y\) without \(\lambda\). Then substitute into the constraint. Before dividing by a variable, check whether it could be zero, and handle that case separately so you don't lose a solution.
Min or max?

The equations find candidates; comparing values decides. On a closed loop like a circle, both a max and a min exist. On an endless line, often only one does: a bowl-shaped \(f\) along a line has a lowest point but no highest.

Example 1Line constraintnotes p. 3

Find the minimum value of \(f(x,y) = x^2 + 4y^2 - 2x + 8y\) subject to the constraint \(x + 2y = 7\).

  1. Name the pieces

    Objective \(f = x^2 + 4y^2 - 2x + 8y\). Constraint \(g(x,y) = x + 2y - 7 = 0\). Minimizing.

  2. Gradients
    \[\nabla f = \langle 2x - 2,\; 8y + 8\rangle, \qquad \nabla g = \langle 1,\; 2\rangle\]
  3. The system
    \[2x - 2 = \lambda, \qquad 8y + 8 = 2\lambda, \qquad x + 2y = 7\]
  4. Eliminate \(\lambda\)

    Substitute \(\lambda = 2x - 2\) into the second equation: \(8y + 8 = 4x - 4\), so \(y = \dfrac{x - 3}{2}\).

  5. Use the constraint

    \(x + 2\cdot\frac{x-3}{2} = 7 \Rightarrow 2x - 3 = 7 \Rightarrow x = 5\), and then \(y = 1\).

  6. Evaluate

    Only one candidate: compute \(f(5, 1)\).

Reveal the answer
Minimum \(= 27\) at \((5, 1)\)\(f(5,1) = 25 + 4 - 10 + 8 = 27\), with \(\lambda = 8\).

Check another way: substitute \(x = 7 - 2y\) to get \(f = 8y^2 - 16y + 35\), a parabola whose lowest point is at \(y = 1\), value 27. It's a minimum because \(f\) is a bowl, which only has a low point along a line.

Example 2Circle constraintnotes p. 4

Find the minimum value of \(f(x,y) = 7x + 4y\) subject to the constraint \(x^2 + y^2 = 32\).

  1. Gradients
    \[\nabla f = \langle 7,\; 4\rangle, \qquad \nabla g = \langle 2x,\; 2y\rangle \quad (g = x^2+y^2-32)\]
  2. The system
    \[7 = 2\lambda x, \qquad 4 = 2\lambda y, \qquad x^2 + y^2 = 32\]

    Neither \(x\), \(y\) nor \(\lambda\) can be 0 (the left sides aren't 0), so dividing is safe.

  3. Link \(x\) and \(y\)

    Divide the second equation by the first: \(\dfrac{4}{7} = \dfrac{y}{x}\), so \(y = \dfrac{4}{7}x\).

  4. Use the constraint
    \[x^2 + \tfrac{16}{49}x^2 = 32 \;\Rightarrow\; \tfrac{65}{49}x^2 = 32 \;\Rightarrow\; x = \pm\tfrac{28\sqrt{130}}{65} \approx \pm 4.91,\quad y = \tfrac47 x \approx \pm 2.81\]
  5. Two candidates, compare them

    \(f = 7x + 4y = 7x + \tfrac{16}{7}x = \tfrac{65}{7}x\). The negative \(x\) gives the smaller value. Compute it.

Reveal the answer
Minimum \(= -4\sqrt{130} \approx -45.61\)at \(\left(-\tfrac{28\sqrt{130}}{65},\, -\tfrac{16\sqrt{130}}{65}\right) \approx (-4.91, -2.81)\). The other candidate gives the maximum, \(+4\sqrt{130}\).

Picture: the level curves of \(7x + 4y\) are parallel straight lines. Slide one across the circle; the first and last lines to touch it are the min and the max.

Topic 3

Three variables: same recipe, one more equation

With \(f(x,y,z)\) and a constraint surface \(g(x,y,z) = 0\), the gradients have three components, so \(\nabla f = \lambda\nabla g\) gives three equations. Add \(g = 0\) and you have four equations for four unknowns \((x, y, z, \lambda)\).

The picture is the same one level up: the level surface of \(f\) touches the constraint surface, so their normal vectors (the gradients) line up.

Example 3Three variablesnotes p. 5

Find the minimum value of \(f(x,y,z) = x^2 + y^2 + z^2\) subject to \(x + y + z = 1\).

  1. Gradients
    \[\nabla f = \langle 2x, 2y, 2z\rangle, \qquad \nabla g = \langle 1, 1, 1\rangle\]
  2. The system

    \(2x = \lambda,\; 2y = \lambda,\; 2z = \lambda\). All three equal the same number, so \(x = y = z\).

  3. Use the constraint

    \(3x = 1\), so \(x = y = z = \tfrac13\).

  4. Evaluate

    Compute \(f\left(\tfrac13, \tfrac13, \tfrac13\right)\).

Reveal the answer
Minimum \(= \tfrac13\) at \(\left(\tfrac13, \tfrac13, \tfrac13\right)\)\(3\cdot\tfrac19 = \tfrac13\).

Meaning: \(x^2+y^2+z^2\) is the squared distance from the origin, so this finds the point on the plane \(x+y+z=1\) closest to the origin.

Topic 4

Applications: turning words into \(f\) and \(g\)

Word problems hide the two functions in plain sight:

  • The thing to make biggest or smallest is the objective \(f\) (volume, cost, distance…).
  • The thing you're limited by is the constraint \(g = 0\) (a fixed amount of material, a budget, a surface you must stay on).

Try the classic box below. You choose the base; the 24 ft² of cardboard decides how tall the walls can be.

ApplicationOpen-top boxnotes p. 6

A rectangular box without a top is to be made from 24 ft² of cardboard. Find the maximum volume of such a box.

  1. Name the variables

    Base \(x\) by \(y\), height \(z\) (feet).

  2. Objective and constraint

    Maximize \(V = xyz\). Cardboard: bottom \(xy\), two walls \(xz\), two walls \(yz\), no lid:

    \[g(x,y,z) = xy + 2xz + 2yz - 24 = 0\]
  3. The system
    \[yz = \lambda(y + 2z),\quad xz = \lambda(x + 2z),\quad xy = \lambda(2x + 2y)\]
  4. Spot the symmetry

    Multiply the first equation by \(x\) and the second by \(y\). Both left sides become \(xyz\), so \(\lambda(xy + 2xz) = \lambda(xy + 2yz)\), which gives \(x = y\). Doing the same with the second and third equations gives \(xy = 2yz\), so \(x = 2z\).

  5. Use the constraint

    With \(x = y = 2z\): \(4z^2 + 4z^2 + 4z^2 = 24\), so \(z^2 = 2\). That makes \(z = \sqrt2\) and \(x = y = 2\sqrt2\).

  6. Evaluate

    \(V = (2\sqrt2)(2\sqrt2)(\sqrt2)\).

Reveal the answer
\(V_{\max} = 8\sqrt2 \approx 11.31\) ft³A square base about 2.83 ft on a side, with walls about 1.41 ft tall: exactly half the base width.

Confirm it on the explorer above: the brightest spot on the map sits at \(x = y \approx 2.83\).

Topic 5

Two constraints

Sometimes a point must satisfy two conditions at once, \(g(x,y,z) = 0\) and \(h(x,y,z) = 0\). Two surfaces usually meet in a curve, and you optimize along that curve.

Lagrange multipliers · two constraints \[\nabla f = \lambda_1\nabla g + \lambda_2 \nabla h, \qquad g = 0, \qquad h = 0\]

Five equations, five unknowns: \(x, y, z, \lambda_1, \lambda_2\).

Why a sum? At the best point, \(\nabla f\) must be perpendicular to the curve. Both \(\nabla g\) and \(\nabla h\) are perpendicular to it too, and every vector perpendicular to the curve is some combination of those two.

Your notes give the setup without an example, so here's one to see it in action.

ExampleTwo constraintsextra, not in notes

Find the maximum of \(f(x,y,z) = x + 2y + 3z\) on the curve where the plane \(x - y + z = 1\) meets the cylinder \(x^2 + y^2 = 1\).

  1. Gradients
    \[\nabla f = \langle 1,2,3\rangle,\quad \nabla g = \langle 1,-1,1\rangle,\quad \nabla h = \langle 2x, 2y, 0\rangle\]
  2. The system
    \[1 = \lambda_1 + 2\lambda_2 x,\quad 2 = -\lambda_1 + 2\lambda_2 y,\quad 3 = \lambda_1\]
  3. Use the easy equation

    \(\lambda_1 = 3\), so \(x = -\dfrac{1}{\lambda_2}\) and \(y = \dfrac{5}{2\lambda_2}\).

  4. Cylinder constraint

    \(\dfrac{1}{\lambda_2^2} + \dfrac{25}{4\lambda_2^2} = 1\), so \(\lambda_2 = \pm\dfrac{\sqrt{29}}{2}\), giving \(x = \mp\tfrac{2}{\sqrt{29}},\ y = \pm\tfrac{5}{\sqrt{29}}\).

  5. Plane constraint, then compare

    \(z = 1 - x + y = 1 \pm \tfrac{7}{\sqrt{29}}\). Evaluate \(f\) at both points.

Reveal the answer
Maximum \(= 3 + \sqrt{29} \approx 8.39\)at \(\left(-\tfrac{2}{\sqrt{29}},\ \tfrac{5}{\sqrt{29}},\ 1 + \tfrac{7}{\sqrt{29}}\right)\). The other point gives the minimum, \(3 - \sqrt{29}\).
Topic 6 · stretch

Optimizing over a whole region

Your practice problem uses an inequality, \(x^2 + y^2 \le 25\): the whole disk, not just the circle. Then the max and min can hide in two places:

  1. Inside the region, at critical points where \(\nabla f = \mathbf{0}\) (Lesson 21's method).
  2. On the boundary \(x^2 + y^2 = 25\), found with Lagrange multipliers.

Collect every candidate from both places and compare.

PracticeDisk regionnotes p. 8

Find the maximum value of \(f(x,y) = -9x^2 - 4x + 3y^2 + 5\) on the region \(x^2 + y^2 \le 25\).

  1. Inside: critical points

    \(f_x = -18x - 4 = 0\) and \(f_y = 6y = 0\) give \(\left(-\tfrac29, 0\right)\), where \(f = \tfrac{49}{9} \approx 5.44\).

  2. Boundary: Lagrange
    \[-18x - 4 = 2\lambda x, \qquad 6y = 2\lambda y, \qquad x^2 + y^2 = 25\]
  3. Don't divide by \(y\)!

    The second equation is \(y(6 - 2\lambda) = 0\), so either \(y = 0\) or \(\lambda = 3\).

    • \(y = 0\): \(x = \pm 5\), giving \(f(5,0) = -240\) and \(f(-5,0) = -200\).
    • \(\lambda = 3\): \(-18x - 4 = 6x\), so \(x = -\tfrac16\) and \(y^2 = 25 - \tfrac1{36} = \tfrac{899}{36}\).
  4. Compare every candidate

    Evaluate \(f\left(-\tfrac16, \pm\tfrac{\sqrt{899}}{6}\right)\) and compare with \(\tfrac{49}{9}\), \(-240\) and \(-200\).

Reveal the answer
Maximum \(= \tfrac{241}{3} \approx 80.33\)on the boundary at \(\left(-\tfrac16, \pm\tfrac{\sqrt{899}}{6}\right)\), matching the solution in your notes.

\(-\tfrac{9}{36} + \tfrac46 + \tfrac{3\cdot 899}{36} + 5 = \tfrac{-3 + 8 + 899 + 60}{12} = \tfrac{964}{12} = \tfrac{241}{3}\).

Lesson 23 · volume over a rectangle

Double integrals over rectangles

The big idea

A single integral adds up thin rectangles to get area. A double integral adds up thin boxes to get volume. In practice you compute it as two ordinary integrals, one inside the other.

Topic 1 · from first principles

Volume and Riemann sums

The region. A rectangle in the \(xy\)-plane is written as a Cartesian product:

\[R = [a,b]\times[c,d] = \{(x,y) \mid a \le x \le b,\ c \le y \le d\}\]

Read it as "every point whose \(x\) is between \(a\) and \(b\) and whose \(y\) is between \(c\) and \(d\)."

The solid. The surface \(z = f(x,y)\) floats above \(R\); \(z\) is the height at each point. We want the volume of the solid \(S\) between \(R\) and the surface.

Chop and stack. Cut \([a,b]\) into \(m\) pieces and \([c,d]\) into \(n\) pieces, so \(R\) becomes a grid of small rectangles \(R_{ij}\):

\[\Delta x = \frac{b-a}{m}, \qquad \Delta y = \frac{d-c}{n}, \qquad \Delta A = \Delta x\,\Delta y\]

Over each small rectangle, build a box as tall as the surface at some sample point \((x^*_{ij}, y^*_{ij})\). Its volume is height × base area, \(f(x^*_{ij}, y^*_{ij})\,\Delta A\). Add every box:

\[V \approx \sum_{i=1}^{m}\sum_{j=1}^{n} f(x^*_{ij}, y^*_{ij})\,\Delta A\]
Riemann box explorer
Sample point
Show

Push \(m\) and \(n\) up and the sum closes in on the exact value. Midpoints get there much faster than corners. Red boxes hang below the plane where \(f\) is negative; they count as negative volume.

The limit. Make the boxes infinitely thin and the approximation becomes exact. That limit is the definition of the double integral:

Double integral \[\iint_R f(x,y)\,dA = \lim_{m,n\to\infty}\ \sum_{i=1}^{m}\sum_{j=1}^{n} f(x^*_{ij}, y^*_{ij})\,\Delta A\]
  • If \(f \ge 0\), the double integral is the volume of the solid under the surface.
  • If \(f\) goes negative, it's a signed volume: parts below the plane subtract, just like net signed area in Calculus 1.
  • Since \(\Delta A = \Delta x\,\Delta y = \Delta y\,\Delta x\), you may write \(dA\) as \(dx\,dy\) or \(dy\,dx\).
Topic 2

Properties of double integrals

These work exactly like their single-integral cousins. Each one comes with a plain-English version.

#PropertyIn words
1\(\displaystyle\iint_R (f \pm g)\,dA = \iint_R f\,dA \pm \iint_R g\,dA\)Split sums and differences apart.
2\(\displaystyle\iint_R cf\,dA = c\iint_R f\,dA\)Constants pull out front.
3\(\displaystyle\iint_R f\,dA = \iint_S f\,dA + \iint_T f\,dA\) when \(R = S\cup T\)Cut the region into pieces and add (pieces may share edges).
4\(f \le g\) on \(R\) \(\Rightarrow \displaystyle\iint_R f\,dA \le \iint_R g\,dA\)A taller function has more volume under it.
5\(\displaystyle\iint_R g(x)h(y)\,dA = \left(\int_a^b g(x)\,dx\right)\!\left(\int_c^d h(y)\,dy\right)\)On a rectangle, an \(x\)-only factor times a \(y\)-only factor splits into two separate single integrals.
Quick check (notes p. 6 #1): if \(\iint_R f\,dA = 5\) and \(\iint_R g\,dA = 5\), what is \(\iint_R (-9f + 5g)\,dA\)?

By properties 1 and 2: \(-9(5) + 5(5) = -20\).

ExampleProperty 5notes p. 6 #2

Evaluate \(\displaystyle\iint_R 3x^2y^2\cos(6y^3)\,dA\) over \(R = \left\{(x,y)\mid -4 \le x \le 3,\ -\tfrac{\pi}{6}\le y \le \tfrac{\pi}{6}\right\}\). (Hint: use the properties.)

  1. Spot the split

    The integrand is (x-only) × (y-only): \(3x^2 \cdot y^2\cos(6y^3)\). The region is a rectangle, so property 5 applies:

    \[\left(\int_{-4}^{3} 3x^2\,dx\right)\left(\int_{-\pi/6}^{\pi/6} y^2\cos(6y^3)\,dy\right)\]
  2. The \(x\) integral

    \(\left[x^3\right]_{-4}^{3} = 27 - (-64) = 91\).

  3. The \(y\) integral: \(u\)-substitution

    Let \(u = 6y^3\), so \(du = 18y^2\,dy\). The antiderivative is \(\tfrac{1}{18}\sin(6y^3)\).

  4. Evaluate the \(y\) part

    At \(y = \pm\tfrac{\pi}{6}\): \(6\left(\tfrac{\pi}{6}\right)^3 = \tfrac{\pi^3}{36}\), so the \(y\) integral is \(\tfrac{1}{18}\left[\sin\tfrac{\pi^3}{36} - \sin\left(-\tfrac{\pi^3}{36}\right)\right] = \tfrac19\sin\tfrac{\pi^3}{36}\).

  5. Multiply

    Multiply the two results.

Reveal the answer
\(\dfrac{91}{9}\sin\!\left(\dfrac{\pi^3}{36}\right) \approx 7.671\)Without property 5 you'd still get here, just with more writing.
Topic 3

Iterated integrals and Fubini's theorem

Computing limits of double sums by hand is painful. The practical way: integrate with respect to one variable, then the other. That's an iterated integral:

\[\int_a^b\!\!\int_c^d f(x,y)\,dy\,dx = \int_a^b\left[\int_c^d f(x,y)\,dy\right]dx\]
  • Work inside-out. The inner integral goes with the inner differential: in \(dy\,dx\), do \(y\) first.
  • Hold the other variable still. While integrating in \(y\), treat \(x\) as a constant. It's partial derivatives in reverse.
  • The inner integral leaves a function of \(x\) alone. Integrate that normally.
Fubini's theorem

If \(f\) is continuous on \(R = [a,b]\times[c,d]\), then

\[\iint_R f(x,y)\,dA = \int_a^b\!\!\int_c^d f(x,y)\,dy\,dx = \int_c^d\!\!\int_a^b f(x,y)\,dx\,dy.\]

On a rectangle, the order doesn't matter. Pick whichever is easier.

Analogy · slicing a loaf

The inner integral is the area of one slice of bread. The outer integral adds up all the slices. Slice the loaf lengthwise or crosswise: same loaf, same total.

Slice the loaf · \(z = 16 - x^2 - 2y^2\)

Orange is the slice being measured; its area is the inner integral. Blue slices are already added up. Run both directions: each finishes at 48.

Example 1Polynomialnotes p. 8

Use Fubini's theorem to evaluate \(\displaystyle\iint_R \left(2x^2 - 7x^2y + 2y\right)dy\,dx\) where \(R = [0,2]\times[3,4]\).

  1. Set up

    \(dy\,dx\): \(y\) runs from 3 to 4 inside, \(x\) from 0 to 2 outside.

    \[\int_0^2\!\!\int_3^4 \left(2x^2 - 7x^2y + 2y\right)dy\,dx\]
  2. Inner integral (\(x\) is a constant)
    \[\int_3^4 \left(2x^2 - 7x^2y + 2y\right)dy = \Big[\,2x^2y - \tfrac72x^2y^2 + y^2\,\Big]_{y=3}^{y=4}\]
  3. Plug in \(y = 4\) and \(y = 3\)

    \((8x^2 - 56x^2 + 16) - (6x^2 - 31.5x^2 + 9) = -\tfrac{45}{2}x^2 + 7\).

  4. Outer integral
    \[\int_0^2 \left(-\tfrac{45}{2}x^2 + 7\right)dx = \Big[-\tfrac{15}{2}x^3 + 7x\Big]_0^2\]
Reveal the answer
\(-46\)\(-60 + 14 = -46\).

Negative? The surface dips below the \(xy\)-plane over most of \(R\), so this is a signed volume. Integrating in the other order (\(dx\,dy\)) also gives \(-46\).

Example 2Trignotes p. 9

Use Fubini's theorem to evaluate \(\displaystyle\iint_R 3x^2\cos(6y)\,dy\,dx\) where \(R = \left[0, \tfrac{\pi}{2}\right]\times\left[\tfrac{\pi}{4}, 1\right]\).

  1. Inner integral (\(3x^2\) is a constant)
    \[\int_{\pi/4}^{1} 3x^2\cos(6y)\,dy = 3x^2\left[\frac{\sin 6y}{6}\right]_{\pi/4}^{1} = \frac{x^2}{2}\left(\sin 6 - \sin\tfrac{3\pi}{2}\right) = \frac{x^2}{2}\left(\sin 6 + 1\right)\]

    Careful: \(\sin 6\) means 6 radians (about −0.279).

  2. Outer integral
    \[\int_0^{\pi/2} \frac{1 + \sin 6}{2}\,x^2\,dx = \frac{1 + \sin 6}{2}\cdot\frac{(\pi/2)^3}{3}\]
  3. Simplify

    \(\frac{(\pi/2)^3}{3} = \frac{\pi^3}{24}\). Multiply it out.

Reveal the answer
\(\dfrac{\pi^3(1 + \sin 6)}{48} \approx 0.4655\)The integrand splits as \(3x^2 \cdot \cos 6y\), so property 5 would have worked here too.
Topic 4

Area and average value

Area

Integrate the constant function 1. A solid of height 1 has volume equal to its base area:

\[A(R) = \iint_R 1\,dA\]

Average value

Total ÷ size, like Calculus 1, but you divide by an area instead of a length:

\[f_{\text{avg}} = \frac{1}{\text{Area of } R}\iint_R f(x,y)\,dA\]
Quick check (notes p. 10): use a double integral to find the area of \(R = [0,3]\times[0,2]\).

\(\int_0^3\!\int_0^2 1\,dy\,dx = \int_0^3 2\,dx = 6\). Same as length × width.

Analogy · leveling a sandbox

Pour sand into a sandbox in a bumpy pile shaped like \(f\). Now rake it perfectly flat. The amount of sand (the volume) hasn't changed, and the flat height you end up with is the average value of \(f\).

Level it out · \(z = 16 - x^2 - 2y^2\) on \([0,2]^2\)
ExampleAverage valuenotes p. 11

Find the average value of \(f(x,y) = 4x + 2x^2y^2 - 9y^3\) over the rectangle \(R = [-4,0]\times[1,2]\).

  1. Area of \(R\)

    Width 4, height 1: area \(= 4\).

  2. Inner integral in \(y\)
    \[\int_1^2\left(4x + 2x^2y^2 - 9y^3\right)dy = \Big[4xy + \tfrac23x^2y^3 - \tfrac94y^4\Big]_1^2 = 4x + \tfrac{14}{3}x^2 - \tfrac{135}{4}\]
  3. Outer integral in \(x\)
    \[\int_{-4}^{0}\left(4x + \tfrac{14}{3}x^2 - \tfrac{135}{4}\right)dx = \Big[2x^2 + \tfrac{14}{9}x^3 - \tfrac{135}{4}x\Big]_{-4}^{0} = 0 - \left(32 - \tfrac{896}{9} + 135\right) = -\tfrac{607}{9}\]
  4. Divide by the area

    \(f_{\text{avg}} = \dfrac{1}{4}\cdot\left(-\dfrac{607}{9}\right)\).

Reveal the answer
\(f_{\text{avg}} = -\dfrac{607}{36} \approx -16.86\)The \(-9y^3\) term dominates, so the "leveled sand" sits below the plane.

Lesson 24 · beyond rectangles

Double integrals over general regions

The big idea

Same iterated integrals, one change: the inner limits become functions. Draw the region, sweep a line across it, and read off where the line enters and leaves. Those curves are your inner limits.

Topic 1 · from first principles

From rectangles to any shape

Here's the trick that lets everything from Lesson 23 carry over. Any bounded region \(D\) fits inside some rectangle \(R\). Define a new function that equals \(f\) on \(D\) and zero elsewhere:

\[g(x,y) = \begin{cases} f(x,y) & \text{if } (x,y) \text{ is in } D\\ 0 & \text{if } (x,y) \text{ is in } R \text{ but not in } D\end{cases}\qquad \iint_D f\,dA = \iint_R g\,dA\]

Points outside \(D\) contribute zero height, so they add nothing. In practice you never build \(g\): describing \(D\) as Type I or Type II lets you skip straight to the iterated integral.

Analogy · a cookie cutter

Roll the dough over the whole rectangle, then cut out your shape. Everything outside the cutter gets thrown away (height 0). The cookie's volume is what's left.

Topic 2

Type I and Type II regions

Type I · vertical sweep

Between two vertical lines, bottom curve to top curve:

\[D = \{a \le x \le b,\ g_1(x) \le y \le g_2(x)\}\]\[\iint_D f\,dA = \int_a^b\!\!\int_{g_1(x)}^{g_2(x)} f\,dy\,dx\]
Type II · horizontal sweep

Between two horizontal lines, left curve to right curve:

\[D = \{c \le y \le d,\ h_1(y) \le x \le h_2(y)\}\]\[\iint_D f\,dA = \int_c^d\!\!\int_{h_1(y)}^{h_2(y)} f\,dx\,dy\]

How to read the limits: drag a vertical line across the region (Type I). It enters through the bottom curve and leaves through the top curve, and those are the inner limits. The outer limits are the first and last \(x\) the line touches: constants. Type II is the same with a horizontal line, reading left curve to right curve.

Outer limits are always constants. Inner limits may depend on the outer variable.

Sweep-line explorer
Choose the order that needs the fewest pieces. If the sweep line's entry or exit curve changes partway across, you must split the integral at that point. Try the parabola region: Type II takes one integral, Type I needs two.
Example 1Both ordersnotes p. 5

Find the volume of the prism whose base is the triangle bounded by the \(x\)-axis and the lines \(y = x\) and \(x = 1\), and whose top lies in the plane \(f(x,y) = 3 - x - y\). Evaluate it as both Type I and Type II.

  1. Sketch

    The triangle has corners \((0,0)\), \((1,0)\) and \((1,1)\). Try it in the explorer above ("Triangle").

  2. Type I (vertical lines)

    \(x\) runs from 0 to 1. A vertical line enters at \(y = 0\) and exits at \(y = x\).

    \[\int_0^1\!\!\int_0^{x}(3 - x - y)\,dy\,dx = \int_0^1\Big[3y - xy - \tfrac{y^2}{2}\Big]_0^{x}dx = \int_0^1\left(3x - \tfrac32x^2\right)dx\]
  3. Type II (horizontal lines)

    \(y\) runs from 0 to 1. A horizontal line enters at \(x = y\) and exits at \(x = 1\).

    \[\int_0^1\!\!\int_y^{1}(3 - x - y)\,dx\,dy = \int_0^1\Big[3x - \tfrac{x^2}{2} - xy\Big]_y^{1}dy = \int_0^1\left(\tfrac52 - 4y + \tfrac32y^2\right)dy\]
  4. Finish both

    Integrate each last line from 0 to 1. They must agree.

Reveal the answer
\(V = 1\) cubic unit, both waysType I: \(\tfrac32 - \tfrac12 = 1\). Type II: \(\tfrac52 - 2 + \tfrac12 = 1\).
Topic 3

A recipe for setting up the limits

  1. Draw the region

    Sketch every boundary curve. Shade the region.

  2. Find where the curves meet

    Set the equations equal. Intersections become the outer limits (or the places to split).

  3. Pick a sweep direction

    Choose the one where the line always enters through the same curve and leaves through the same curve.

  4. Read the limits off the sweep line

    Inner: entry curve to exit curve (functions). Outer: first to last position of the line (numbers).

Example 2Type II regionnotes p. 6

Evaluate \(\displaystyle\iint_D (3x^2 + y^2)\,dA\) where \(D = \{(x,y)\mid -2 \le y \le 3,\ y^2 - 3 \le x \le y + 3\}\).

  1. Draw it

    \(x = y^2 - 3\) is a parabola opening right with its vertex at \((-3, 0)\). \(x = y + 3\) is a line. They meet where \(y^2 - 3 = y + 3\), so \(y = -2\) and \(y = 3\), at the points \((1,-2)\) and \((6,3)\). See "Parabola" in the explorer.

  2. Recognize Type II

    The description already says \(y\) is outer and \(x\) runs from the parabola (left) to the line (right):

    \[\int_{-2}^{3}\!\!\int_{y^2-3}^{y+3}(3x^2 + y^2)\,dx\,dy\]
  3. Inner integral in \(x\)
    \[\Big[x^3 + y^2x\Big]_{x=y^2-3}^{x=y+3} = \left[(y+3)^3 + y^2(y+3)\right] - \left[(y^2-3)^3 + y^2(y^2-3)\right]\]

    Expand and simplify:

    \[-y^6 + 8y^4 + 2y^3 - 12y^2 + 27y + 54\]
  4. Outer integral in \(y\)
    \[\int_{-2}^{3}\left(-y^6 + 8y^4 + 2y^3 - 12y^2 + 27y + 54\right)dy\]

    Term by term: \(-\tfrac{2315}{7} + 440 + \tfrac{65}{2} - 140 + \tfrac{135}{2} + 270\).

Reveal the answer
\(\dfrac{2375}{7} \approx 339.29\)The non-\(\frac{1}{7}\) terms add to 670, and \(670 - \tfrac{2315}{7} = \tfrac{4690 - 2315}{7}\).

As Type I this would need two integrals (split at \(x = 1\)). Type II was the right call.

Volume, area and average value

WantIntegrateTip

ExampleVolumenotes p. 7

Let \(S\) be the solid in the first octant under the plane \(8x + 2y + 2z = 32\). Find the volume of \(S\).

  1. Solve for the height

    \(z = 16 - 4x - y\).

  2. Find the floor region

    "First octant" means \(x, y, z \ge 0\). The plane hits the floor (\(z = 0\)) along \(4x + y = 16\), so \(D\) is the triangle with corners \((0,0)\), \((4,0)\), \((0,16)\).

  3. Set up (Type I)
    \[V = \int_0^4\!\!\int_0^{16-4x}(16 - 4x - y)\,dy\,dx\]
  4. Inner integral

    \(\left[(16-4x)y - \tfrac{y^2}{2}\right]_0^{16-4x} = \tfrac12(16-4x)^2\).

  5. Outer integral

    \(\int_0^4 \tfrac12(16-4x)^2\,dx\). Use \(u = 16 - 4x\).

Reveal the answer
\(V = \dfrac{512}{3} \approx 170.67\) units³\(\tfrac18\int_0^{16}u^2\,du = \tfrac{16^3}{24}\). Check: a tetrahedron with legs 4, 16, 16 has volume \(\tfrac16\cdot4\cdot16\cdot16 = \tfrac{512}{3}\).
ExampleAreanotes p. 8

Find the area of the region bounded by \(y = \dfrac{1}{2x}\), \(y = 2e^x\), and the lines \(x = 1\) and \(x = 7\).

  1. Which curve is on top?

    At \(x = 1\): \(2e \approx 5.4\) versus \(0.5\). \(2e^x\) grows and \(\tfrac{1}{2x}\) shrinks, so \(2e^x\) stays on top.

  2. Set up (Type I)
    \[A = \int_1^7\!\!\int_{1/(2x)}^{2e^x} 1\,dy\,dx = \int_1^7\left(2e^x - \frac{1}{2x}\right)dx\]
  3. Integrate

    \(\left[2e^x - \tfrac12\ln x\right]_1^7\). Remember \(\ln 1 = 0\).

Reveal the answer
\(A = 2e^7 - 2e - \tfrac12\ln 7 \approx 2186.86\) units²The \(2e^7\) term does almost all the work: the top curve shoots up fast.
ExampleAverage valuenotes p. 9

The region \(D\) is bounded by \(y = 0\), \(x = y - 7\), and \(x = 7 - y\). Find the average value of \(f(x,y) = 9x + 5y\) on \(D\).

  1. Sketch

    A triangle with corners \((-7,0)\), \((7,0)\), \((0,7)\). Horizontal lines go from \(x = y - 7\) to \(x = 7 - y\): Type II, one piece. ("Wide triangle" in the explorer.)

  2. Area

    \(\int_0^7\left[(7-y) - (y-7)\right]dy = \int_0^7 (14 - 2y)\,dy = 49\).

  3. Inner integral of \(f\)

    \(\int_{y-7}^{7-y}(9x + 5y)\,dx = \left[\tfrac92x^2 + 5xy\right]_{y-7}^{7-y} = 0 + 5y(14 - 2y)\). The \(9x\) part cancels because the triangle is symmetric about the \(y\)-axis.

  4. Outer integral

    \(\int_0^7 (70y - 10y^2)\,dy = 1715 - \tfrac{3430}{3} = \tfrac{1715}{3}\).

  5. Divide

    \(f_{\text{avg}} = \dfrac{1715/3}{49}\).

Reveal the answer
\(f_{\text{avg}} = \dfrac{35}{3} \approx 11.67\)Shortcut insight: the average of \(y\) over this triangle is \(\tfrac73\) (one-third of its height), so the average of \(5y\) is \(\tfrac{35}{3}\).

Cheat sheet

Lagrange · 1 constraint
\(\nabla f = \lambda\nabla g,\ \ g = 0\)

Solve, list candidates, compare \(f\).

Lagrange · 2 constraints
\(\nabla f = \lambda_1\nabla g + \lambda_2\nabla h\)

Plus \(g = 0\) and \(h = 0\).

Regions with ≤

Interior: \(\nabla f = \mathbf 0\). Boundary: Lagrange. Compare all.

Double integral
\(\displaystyle\iint_R f\,dA = \lim\sum\sum f(x^*_{ij},y^*_{ij})\Delta A\)
Fubini (rectangles)
\(\displaystyle\int_a^b\!\!\int_c^d f\,dy\,dx = \int_c^d\!\!\int_a^b f\,dx\,dy\)
Splits (property 5)
\(\displaystyle\iint_R g(x)h(y)\,dA = \int_a^b g\,dx \cdot \int_c^d h\,dy\)
Type I
\(\displaystyle\int_a^b\!\!\int_{g_1(x)}^{g_2(x)} f\,dy\,dx\)

Vertical sweep: bottom to top.

Type II
\(\displaystyle\int_c^d\!\!\int_{h_1(y)}^{h_2(y)} f\,dx\,dy\)

Horizontal sweep: left to right.

Area & average
\(\displaystyle A = \iint_D 1\,dA,\quad f_{\text{avg}} = \tfrac{1}{A}\iint_D f\,dA\)

Common mistakes

  • Dividing by a variable in a Lagrange system without checking whether it could be 0.
  • Forgetting to compare all candidates (and the interior, for ≤ regions).
  • Integrating the wrong variable first: the inner differential goes with the inner limits.
  • Putting a variable in an outer limit. Outer limits are always numbers.
  • Forgetting to treat the other variable as a constant in the inner integral.
  • Using degrees: \(\sin 6\) means 6 radians.
  • Forgetting to divide by the area for an average value.
